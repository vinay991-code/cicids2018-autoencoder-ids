Flow features follow CICFlowMeter. Packets are turned into the 68 flow features by a port of the flow logic of CICFlowMeter, the tool that made the training data (including its quirks). Check results load here. A flag is still a lead to inspect in Wireshark, not a verdict: the models were trained on one 2018 lab network and detection of real attacks on other networks was not measured. The column "Out of range" counts features outside the training range: ordinary test flows almost never have any, so a flow with several is unlike the training data. Only IPv4 packets are used (TCP, UDP, and other IP protocols as protocol 0, like the training data). The uploaded file is deleted from disk once read; results stay in memory on this computer.
